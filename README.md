# Superhero Intelligence System

Hero vs villain from six ability scores: Decision Tree, KNN, K-Means, Agglomerative clustering and two Keras MLPs.

- `superhero_project.ipynb`: full solution, executed (data prep, Tasks 1-3, tables T1-T11, graphs G1-G16, answers Q1-Q12)
- `superhero_project.html`: same notebook as a static page
- `data/`: `train.csv`, `test.csv` (Hugging Face `jrtec/Superheroes`)

Run: `python -m venv .venv && source .venv/bin/activate && pip install -r requirements.txt && jupyter lab`
